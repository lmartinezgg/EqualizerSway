# EqualizerSway

EqualizerSway employs a real-time-processing controller that modulates audio streams through auto-scaling modules.

EqualizerSway is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/EqualizerSway.git`
2. `cd EqualizerSway`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure EqualizerSway, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
